Data: Descriptive Statistics & Displays

Population, Sample, Parameters, Statistics

You can't test every steam pipe in a power station until it fails — so you test a handful of specimens and use them to say something about all the steel of that grade. That's the core idea behind every method in this unit.

The four core terms
  • Population — the complete set of all possible observations of interest (e.g. all the steel of a given grade ever manufactured)
  • Sample — the subset actually observed (e.g. the specimens tested)
  • Parameter — a number describing the population (e.g. true mean, true standard deviation) — usually unknown
  • Statistic — a number describing the sample (e.g. sample mean) — used to estimate the parameter
Worked example — steam pipe failure times

Steam pipes made of a low-alloy ferritic steel are tested for time-to-failure. Small specimens cut from different batches are stressed and heated until they fail.

Population: failure times of all the steel manufactured to this grade
Sample: failure times of the specimens actually tested
Data: 4.3, 6.4, 5.3, 5.0, 3.8, 5.5, 4.4, 6.7, 6.0, 7.1, 5.3, 8.8 (years) — used throughout this unit

Sampling Methods

A probability sampling method uses random selection, so every unit in the population has a known chance of being chosen. Non-probability sampling relies on convenience and is prone to bias.

Sampling can also be done with replacement (a unit can appear more than once) or without replacement (a unit appears at most once).

Simple random sampling

Every item in the population has an even chance of being selected. The baseline method — unbiased but can miss small subgroups by chance.

Stratified random sampling

The population is first divided into strata of similar observations, then a simple random sample is taken from each stratum — guarantees every subgroup is represented.

Cluster random sampling

The population is divided into clusters (not necessarily homogeneous), a random sample of whole clusters is selected, and sampling occurs within them.

Why Sampling Matters in Machine Learning

Generalisation

Random sampling avoids bias so a model generalises to real-world data. Stratified sampling ensures important subgroups aren't overlooked during training.

Computational cost

Large datasets are expensive to process. Efficient sampling reduces the data used for training, allowing faster training on less powerful hardware.

Class imbalance

Plain random sampling can leave a test set with very few (or no) examples of a rare but important class. Stratified sampling addresses this directly.

Mini-batch sampling

A small, randomly selected subset of the training set is used at each iteration of model training, rather than the full dataset every time.

Cross-validation

Used at the assessment phase to check how well a model generalises to unseen data. Split the dataset into k folds (e.g. 5 or 10). For each fold: train on the other k−1 folds, validate on the held-out fold. Repeat k times, using a different fold each time, and average the performance. This helps detect overfitting and is especially useful when the dataset is small.

Data Quality

"Garbage in, garbage out." Before trusting any statistic, check the data itself:

Accuracy

Is the data correct and free from errors?

Completeness

Are all required fields populated?

Consistency

Is data uniform across sources and systems?

Timeliness

Is the data up to date and available when needed?

Validity

Does the data conform to expected rules and formats?

Uniqueness

Are there duplicate records?

Descriptive Statistics

Descriptive statistics condense a dataset into useful quantities: a measure of location (where the centre is), a measure of scale (how spread out the data is), plus displays used alongside them.

Sample mean
$$\bar{X} = \frac{1}{n}\sum_{i=1}^{n} X_i$$
nsample size
X̄arithmetic average of the observations
Sample variance & standard deviation
$$s^2 = \frac{\sum_{i=1}^{n}(X_i-\bar{X})^2}{n-1} \qquad s = \sqrt{s^2}$$
s²variance — squared units of the original data
sstandard deviation — same units as the original data

Divided by n − 1, not n, because using the sample mean (rather than the true population mean) to compute deviations removes one degree of freedom — dividing by n would systematically underestimate the population variance.

Worked example — mean, variance, standard deviation

Using the steam pipe failure data (n = 12): 4.3, 6.4, 5.3, 5.0, 3.8, 5.5, 4.4, 6.7, 6.0, 7.1, 5.3, 8.8

X̄ = sum of all values ÷ 12 = 5.717 years
Variance = Σ(Xᵢ − 5.717)² ÷ 11 = 1.9324
Standard deviation = √1.9324 = 1.3901 years

Quartiles

Quartiles divide the ordered dataset into four equal parts. Q1 is the lower quartile, Q2 is the median, Q3 is the upper quartile. Different software packages compute quartiles slightly differently — for hand calculations, use the method below.

Quartile position & interpolation
$$\ell_q = \frac{n+3}{4}\ (n\text{ odd}) \qquad \ell_q = \frac{n+2}{4}\ (n\text{ even})$$
$$Q_1 = \frac{X_{(\ell_q-1)/2} + X_{(\ell_q+1)/2}}{2} \qquad Q_3 = \frac{X_{(n+1-(\ell_q-1)/2)} + X_{(n+1-(\ell_q+1)/2)}}{2}$$

Used only when ℓq is not an integer; if it is an integer, Q1 = X(ℓq) and Q3 = X(n+1−ℓq) directly.

Worked example — quartiles

n = 12 (even), so ℓq = (12+2)/4 = 3.5

Q1 = average of the 3rd and 4th ordered values = (4.4 + 5.0)/2 = 4.7
Q3 = average of the 9th and 10th ordered values = (6.4 + 6.7)/2 = 6.55
IQR = Q3 − Q1 = 6.55 − 4.7 = 1.85

Displaying Data

Stem-and-leaf diagram

Groups data by a leading digit (stem) and lists the remaining digits (leaves). Old-fashioned but a fast way to see the shape and spread of small datasets.

Box plot

Shows Q1, median, Q3, the IQR box, the fences, and any outliers beyond them in one picture.

Histogram

Shows the frequency of values falling into ranges (bins) — absolute frequency (count) or relative frequency (proportion of total).

Box plot fences
$$\text{step} = 1.5 \times IQR \qquad UIF = Q_3 + \text{step} \qquad LIF = Q_1 - \text{step}$$
UIFupper inner fence — largest data point within 1.5×IQR of Q3
LIFlower inner fence — smallest data point within 1.5×IQR of Q1

Points beyond the fences are flagged as outliers. Note the whiskers on the plot itself extend only to the most extreme actual data point still inside the fence, not to the fence value itself.

Reading skew from mean vs median
  • Symmetric: mean ≈ median
  • Right (positive) skew: mean > median — long tail toward high values
  • Left (negative) skew: mean < median — long tail toward low values

Outliers & Missing Data

An outlier is an extreme value, much larger or smaller than the rest of the data. Outliers can indicate data entry errors or genuine rare events, and can skew models if left unexamined — but not every outlier should be removed. Always investigate before deciding.

For missing data, plotting where values are missing helps reveal patterns. Little's MCAR test checks whether data is Missing Completely At Random (useful across multiple variables); a chi-square test can check for association between missingness and other variables.

Preprocessing

Raw data is rarely ready for a model — this is covered in more depth in the PC lab sessions, but the key ideas:

Missing values & outliers

Remove or interpolate missing data. Decide deliberately how to handle outliers rather than deleting them by default.

Normalisation (min-max)

Rescales data to a fixed range, typically 0 to 1. Needed for algorithms like K-Means and SVM that are sensitive to feature scale.

Standardisation (z-score)

Rescales data to have a mean of 0 and a standard deviation of 1.

MCQ Traps

Plausible-but-wrong claims the exam uses. Read each one. Know what's actually true.

Unit 1 — Data & Descriptive Statistics

U1 — T1
"Sample variance is calculated by dividing by n."
FALSE. Sample variance divides by n − 1, not n. Dividing by n underestimates the true population variance because the sample mean, not the true mean, was used to compute the deviations.
U1 — T2
"A parameter is calculated from the sample; a statistic describes the population."
FALSE. It's the other way round: a parameter describes the population (usually unknown), a statistic is calculated from the sample and used to estimate it.
U1 — T3
"Simple random sampling always protects against class imbalance."
FALSE. Simple random sampling can still produce a test set with very few, or no, examples of a rare class. Stratified sampling is the method that specifically protects against this.
U1 — T4
"In cross-validation, you train and validate on the same fold each time."
FALSE. In k-fold cross-validation you train on k−1 folds and validate on the remaining, held-out fold, repeating so a different fold is used for validation each time, then averaging.
U1 — T5
"If the mean is greater than the median, the data is left-skewed."
FALSE. Mean > median indicates right (positive) skew — a long tail toward higher values. Mean < median indicates left (negative) skew.
U1 — T6
"The box plot whiskers always extend exactly to the fence values."
FALSE. The fences (UIF, LIF) are calculation limits used to flag outliers. The whiskers on the plot itself extend only to the most extreme actual data point that still falls inside the fence — not to the fence value itself.
U1 — T7
"All outliers should be removed from a dataset before analysis."
FALSE. Outliers should always be investigated, but not all outliers need to be removed — some represent genuine rare events that are important to the analysis.
U1 — T8
"Normalisation and standardisation are the same technique."
FALSE. Normalisation (min-max scaling) rescales data to a fixed range, typically 0–1. Standardisation (z-score) rescales data to a mean of 0 and standard deviation of 1. They are used for different purposes and produce different scales.
U1 — T9
"Every statistical software package computes quartiles the same way."
FALSE. Different software packages can use different quartile methods and give different results. For hand calculations, use the method given in the lecture notes rather than assuming a software default.
U1 — T10
"Cluster sampling requires each cluster to be internally homogeneous, like strata in stratified sampling."
FALSE. Clusters are not necessarily homogeneous — that's the key difference from strata. A random sample of whole clusters is taken, and sampling then occurs within the selected clusters.
U1 — T11
"Non-probability sampling gives every unit a known, equal chance of selection."
FALSE. That description applies to probability sampling. Non-probability sampling relies on convenience and does not give every individual an equal (or known) chance of being included.
U1 — T12
"Standard deviation and variance are expressed in the same units."
FALSE. Variance is in the squared units of the original data (e.g. years²). Standard deviation, its square root, is in the same units as the original data (e.g. years) — which is why it's usually the more interpretable measure.
